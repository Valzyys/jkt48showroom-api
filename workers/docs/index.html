01 / QUICK START

Request pertama

Endpoint berita dan member dapat dipanggil tanpa API key.

curl 'https://api.jkt48connect.app/api/news?page=1&perpage=10'

Respons tiap endpoint mengikuti handler: array, object, teks, playlist, atau binary. Tidak ada envelope sukses tunggal.

02 / AUTHENTICATION

Akses sesuai kebutuhan

Publik: news, members, theater, jadwal dan data live.

User: Authorization: Bearer ACCESS_TOKEN. Refresh menggunakan X-Refresh-Token; session Showroom menggunakan X-SR-Token.

Server: recent memakai API key/HMAC. Weekly memakai query api_key. Admin membutuhkan user dengan ID yang terdaftar.

Panduan JavaScript, Python, CORS, pagination & error

JavaScript / Node.js

const base = 'https://api.jkt48connect.app';

Pagination & waktu

News, theater dan jkt48event memakai page dan perpage: default 1 dan 10, perpage maksimal 30. Halaman dibatasi ke jumlah halaman yang tersedia. Respons menyertakan total_count. Waktu ISO dengan Z adalah UTC; tampilkan WIB dengan timezone Asia/Jakarta.

CORS & form

Di browser, beberapa route membutuhkan origin yang diizinkan. Konfigurasi saat deployment: ORIGINS=http://localhost:3000. Domain frontend produksi perlu ditambahkan oleh pengelola. Form mutasi harus memakai Origin yang diizinkan atau konteks CSRF yang valid. API key dan secret server digunakan dari backend; contoh di halaman ini menggunakan placeholder.

Login & refresh

POST /api/auth/login menerima form account_id, password, dan opsional captcha_word. Sukses menghasilkan access_token, refresh_token, dan user. Simpan token dengan aman di aplikasi. Respons dapat memperbarui token lewat X-Access-Token, X-Refresh-Token, dan X-SR-Token. Tidak ada route refresh terpisah; middleware menggunakan refresh header.

Filter recent

page, perpage (maks. 30), group, room_id, type=all|showroom|idn, search, filter=active|graduated, sort=date|gift|views|duration, order=-1|1. date berupa JSON URL-encoded {"start":MILLISECONDS,"end":MILLISECONDS}.

Signature HMAC

Kirim x-nonce unik, x-timestamp Unix seconds, x-signature HMAC-SHA256 hex atas <nonce>.<timestamp>, dan opsional x-source. Toleransi 240 detik; nonce hanya sekali pakai. Secret sumber diberikan pengelola. API key server dapat dipakai sebagai alternatif pada route recent.

Weekly

type=theater|gift|live|duration|viewers|nolive|follower (default live), platform=showroom|idn|all, format=raw|normal|extended (default normal). Endpoint ini membaca api_key dari query, bukan header.

WebSocket & webhook

/ws?token=JWT memakai Upgrade WebSocket, JWT HS256 dan frame binary CBOR. Encode string PING, listen jkt48 hinatazaka46, atau view /member/SLUG. Decode balasan CBOR sebagai string; broadcast data adalah JSON di dalam string. Reconnect dan subscribe ulang setelah terputus.

Webhook Saweria menerima callback resmi dan Saweria-Callback-Signature. Signature HMAC-SHA256 menggabungkan nilai version, id, amount_raw, donator_name, donator_email berurutan tanpa separator. Sukses berupa teks success; ID duplikat idempotent.

HTTP errors

400 input invalid · 401 autentikasi · 403 CSRF/akses · 404 data/route atau admin tersembunyi · 409 konflik · 413 payload · 429 rate limit · 502 upstream · 503 konfigurasi/storage/upstream · 504 timeout.

{"status":401,"message":"Unauthorized!","path":"/api/user"}

Error sinkronisasi dapat menambahkan code, upstream_status, serta header Retry-After. Retry mengikuti header itu; jangan menganggap array kosong sebagai jaminan collector aktif.

Tentang contoh respons

Contoh bertanda “produksi” diambil pada 13 Oktober 2026. Preview dipersingkat; unduhan menyimpan respons lengkap. Endpoint privat memakai contoh penolakan atau format dari source. Login, mutasi admin, TURN dan webhook tidak dieksekusi dari UI ini. Route yang bergantung pada collector, YouTube, Saweria atau session upstream membutuhkan konfigurasi tambahan.

Member dan birthday telah diperbaiki. Profil tanpa tanggal lahir dilewati; ulang tahun dihitung dengan WIB. Gambar JKT48 mengarah ke /media/jkt48/... dan dilayani dari R2 setelah diunduh melalui scraper. Server API key tersedia bagi admin pada control admin.
